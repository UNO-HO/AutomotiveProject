# 편안길

**앞으로 갈 길을 미리 읽어, 뒷좌석 아이의 멀미를 시작되기 전에 막는 Pleos Connect 앱**

현대자동차그룹 차량용 앱 개발 공모전 출품작입니다.

## 왜 만들었나

아이를 태우고 장거리를 가면 "아빠, 속이 안좋아"라는 말이 나올 때는 이미 늦습니다. 산길 한가운데라 세울 곳도 없는 경우가 많습니다. 어린아이는 멀미약도 마음 놓고 쓰기 어렵습니다.

그런데 멀미를 일으키는 원인(굽은 길, 가다 서기, 급가감속)은 차가 이미 알고 있습니다. 내비게이션 경로와 주행 데이터에 다 들어 있습니다. 편안길은 이 데이터로 **멀미가 시작되기 전에** 운전자와 아이에게 할 일을 알려 줍니다.

## 주요 기능

| 기능 | 설명 |
| --- | --- |
| 멀미 위험 지수 | 차량 속도와 회전율로 앞뒤·좌우 흔들림을 구하고, 멀미를 일으키는 저주파 흔들림(0.08~0.63Hz)을 누적합니다(ISO 2631-1 멀미 누적량 개념). 정차해 쉬면 회복됩니다. |
| 앞길 멀미 예보 | 내비 회전 안내(TBT) 지점의 밀도로 앞으로 30km를 2km 단위로 나눠 편안 / 보통 / 위험으로 보여 줍니다. |
| 휴식 제안 | 위험 구간이 끝날 때쯤 지수가 높을 것으로 예상되면, 구간에 들어서기 전에 쉬어 가자고 제안하고 내비의 휴게소 검색을 엽니다. |
| 운전 계기판 | 최근 15초의 흔들림을 "부드러워요 / 조금 거칠어요 / 너무 과격해요" 세 단계로 보여 줍니다. |
| 운전 코칭 | 급가감속·급회전이 반복되면 짧게 음성으로 알립니다. 잔소리가 되지 않도록 5분 간격, 주행당 4회로 제한합니다. |
| 아이 오디오 큐 | 위험 구간 직전, 뒷좌석 아이에게 차량 스피커로 창밖(먼 곳)을 보도록 말을 겁니다. |
| 가족 맞춤 | 정차 중 "아이 상태" 한 번 탭으로 가족별 멀미 민감도를 학습합니다. 따로 설정할 것이 없습니다. |
| 편안함 리포트 | 도착 후 편안함 점수, 운전 느낌 비율, 지수 변화 그래프, 여정 기록, 가장 흔들렸던 순간을 보여 줍니다. |

운전자의 주의를 뺏지 않도록 주행 중 조작은 휴식 제안의 큰 버튼 두 개로 제한하고, 나머지 입력은 정차 중에만 받습니다. 내비와 나란히 띄운 좁은 창에서는 한 줄 배치로 자동 전환됩니다.

## 실행 방법

1. Android Studio(JDK 17)에서 프로젝트를 엽니다. Gradle 동기화 때 Pleos 공개 Maven 저장소에서 SDK를 받습니다.
2. Pleos Connect Emulator를 실행합니다.
3. 앱을 실행하고 차량 속도 권한을 허용합니다.
4. 모드를 고르고 **출발**을 누릅니다.
   - **시연 모드:** 59분짜리 가상 주행(서울 → 강원도 산길)을 15배속, 약 4분 동안 재생합니다. 에뮬레이터에서는 내비 위치가 실제 경로를 따라 움직이지 않으므로 시연은 이 모드로 합니다.
   - **실차 연동:** 속도·기어는 AAOS Car API에서, 앞길 정보는 Pleos NaviHelper에서 받습니다. 내비에서 목적지를 정하면 경로 예보가 켜집니다.

### 시연 흐름 (시연 모드)

| 가상 시각 | 구간 | 화면과 음성 |
| --- | --- | --- |
| 0~6분 | 도심 | 가다 서기로 지수가 천천히 오르고, 예보 막대 끝에 위험 구간이 보입니다. |
| 6~16분 | 고속도로 | 정속 주행에서는 지수가 거의 오르지 않습니다. |
| 13분 | 고속도로 | 휴식 제안 카드가 뜹니다. |
| 16~24분 | 정체 | 가다 서기로 지수가 다시 오릅니다. |
| 29분 | 휴게소 정차 | "아이 상태 어때요?" 카드가 뜨고, 쉬는 동안 지수가 회복됩니다. |
| 38분 | 산길 직전 | 아이에게 오디오 큐, 운전자에게 회생제동 제안을 합니다. |
| 39~57분 | 산길 | 지수가 "멀미 주의"까지 오르고, 계기판과 커브 코칭이 반응합니다. |
| 59분 | 도착 | 편안함 리포트가 나옵니다. |

## 테스트 환경

- Pleos Connect Emulator v2.1.0 (API 34)
- Android Gradle Plugin 8.7.3, Kotlin 2.0.21, Jetpack Compose
- Pleos SDK: NaviHelper 3.0.5, TextToSpeech 3.3.1

## APK

`apk/` 폴더에 release APK가 있습니다.

## 사용한 SDK / API

| 용도 | API |
| --- | --- |
| 속도, 기어 | AAOS `CarPropertyManager` (`PERF_VEHICLE_SPEED`, `GEAR_SELECTION`) |
| 회전율 | 헤드유닛 자이로를 중력 방향으로 투영해 장착 각도와 상관없이 요레이트를 구함 |
| 앞길 정보, 남은 거리 | Pleos NaviHelper: `getTBTInfo`, `getDestinationInfo`, `onNavigationStatus` |
| 휴게소 찾기 | NaviHelper `requestNavigationScreen(SearchPlace("휴게소"))` |
| 음성 안내 | Pleos TextToSpeech (ON_DEVICE), 실패 시 안드로이드 기본 TTS |

## 구조

```
app/src/main/java/com/pyeonangil/
  engine/   멀미 계산 엔진 (순수 Kotlin, 안드로이드 의존성 없음)
    RideEngine.kt       지수·예보·이벤트를 만드는 중심 로직
    MotionFilters.kt    속도 → 가속도, 대역 통과 필터, 멀미 누적량
    RouteForecaster.kt  회전 안내 밀도로 앞길 예보
    DriverCoach.kt      급이벤트 감지, 코칭, 가족 민감도, 점수
    DemoTrip.kt         시연용 가상 주행
    Tuning.kt           모든 설계값
  data/     실차(Pleos) / 시연 데이터 소스, 가족 프로필 저장
  voice/    음성 안내
  ui/       Compose 화면
app/src/test/   엔진 단위 테스트
```

멀미 기준값은 "도심·고속도로·정체에 굽은 길이 조금 섞인 보통 주행에서 1시간 반쯤 타면 멀미가 나는 사람"을 출발점으로 잡았고, 가족 피드백으로 조정됩니다. 모든 설계값은 `Tuning.kt`에 모아 두었습니다.
